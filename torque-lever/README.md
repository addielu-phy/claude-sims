# 2-5 力矩與槓桿原理｜互動解說（Claude 版）

國中理化（國三，翰林版第五冊 2-5）互動教材：力矩、力臂、轉動平衡、槓桿原理與三種槓桿。由 Claude 製作。

線上版：<https://addielu-phy.github.io/claude-sims/torque-lever/>

（本資料夾屬於 [claude-sims](../) 總庫：所有 Claude 版互動模擬集中在這裡。）

## 網頁內容

- **實驗室 A：力臂偵測器（扳手）**：拖曳施力點、調整夾角與力的大小，畫出力的作用線和「轉軸到作用線的垂直距離」。示範垂直、30°、沿桿三種情況，並提醒「把 r 當力臂」的錯誤。
- **實驗室 B：米尺槓桿**：點米尺掛 10／20／50 gw 砝碼，拖曳移動、往下拖離即移除；可移動支點、可考慮米尺重量（100 gw 在 50 cm）。即時列出每個力的力臂、力矩、方向與合計，平衡時顯示支點撐力。
- **實驗室 C：槓桿分類器**：拖曳支點、施力點、抗力點，自動判斷三種槓桿、需要的施力、省力或費力；「慢慢施力」動畫顯示兩端移動距離與「功相等」。內建翹翹板、剪刀、開瓶器、獨輪車、鑷子、釣竿。
- **七個情境例題**：翹翹板、米尺掛砝碼、米尺重量、扳手斜施力、獨輪車、釣竿、111 年會考第 33 題。每題逐步計算＋技巧，可一鍵載入實驗室驗證。
- **考試技巧與常見陷阱**十條、**觀念檢查**三題（點選作答）。

## 物理模型

- 力臂 d ＝ r·sinθ（轉軸到力的作用線的垂直距離）；力矩 L ＝ F·d。
- 米尺：重力鉛直向下，力臂為到支點的水平距離；轉動平衡 ⇔ Σ m(x − p) ＝ 0；平衡時支點撐力 ＝ 總重。均勻米尺重量作用在 50 cm。
- 槓桿：F ＝ R × 抗力臂 ÷ 施力臂；移動距離與力臂成正比，F·s_F ＝ R·s_R（不計摩擦）。
- 米尺失衡時的轉動為示意動畫（轉到約 9° 停住），不代表真實轉動速度。
