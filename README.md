# claude-sims：Claude 版互動物理模擬總庫

由 Claude 製作的高中物理互動教材，集中放在這個 repo。

總目錄：<https://addielu-phy.github.io/claude-sims/>

| 模擬 | 主題 | 線上版 |
|---|---|---|
| [box-slide-or-tip](box-slide-or-tip/) | 範例 11：推木箱，先滑動還是先傾倒（摩擦力、力矩、正向力作用點） | <https://addielu-phy.github.io/claude-sims/box-slide-or-tip/> |

## 結構

- 每個模擬一個資料夾，資料夾內是可直接開啟的靜態網頁（`index.html`）與自己的 `README.md`、`VALIDATION.md`、稽核腳本。
- 根目錄 `index.html` 是總目錄頁；新增模擬時同步更新上表與目錄頁。
- GitHub Pages：Settings → Pages → Deploy from a branch → `main` / `(root)`。
