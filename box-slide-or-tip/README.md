# 推木箱：先滑動，還是先傾倒？（範例 11，Claude 版）

高中物理互動教材：摩擦力、力矩平衡與正向力作用點。由 Claude 製作。

線上版：<https://addielu-phy.github.io/claude-sims/box-slide-or-tip/>

（本資料夾屬於 [claude-sims](../) 總庫：所有 Claude 版互動模擬集中在這裡。）

## 題目

重 2 kgw 的均勻木箱寬 2 m、高 4 m，μs = 0.5、μk = 0.4。在高度 h 的 P 點施水平力 F 向左推。

1. 恰將滑動、同時恰將繞 x 軸轉動，h = ?　**答：2 m**
2. 等速向左移動且不傾倒，h 的最大值 = ?　**答：2.5 m**
3. h = 1.5 m、F = 0.8 kgw，正向力對 x 軸的力矩與作用點？　**答：0.8 kgw·m（逆時針）；距 O 點 0.4 m**

## 網頁內容

- **動畫**：木箱、推力 F、重力 W、正向力 N、摩擦力 f 的大小與方向，力臂，以及正向力作用點 d 隨推力移動。
- **兩種情境**：「從靜止慢慢加力」（F 由 0 增加，看先滑動還是先傾倒）、「等速滑動中」（F 鎖定為 μkN）。
- **面板**：即時受力表、對 x 軸的力矩長條圖與代入數字的算式、d 的位置量尺。
- **F–h 判斷圖**：靜止／先滑動／先傾倒三區，兩條臨界線的交點就是第 (1) 題；可直接點選或拖曳。
- **解題區**：解題前的設定、三小題逐步計算（每一步都寫出代入過程）、換軸驗算、常見迷思、想一想。
- **進階**：可改變 μs、μk，觀察判斷圖的交點移動。

## 物理模型

- 平衡（靜止或等速平移）：N = W、f = F、對過 O 點的 x 軸 F·h − W·(b/2) + N·d = 0。
- 不滑動：F ≤ μsN；不傾倒：d ≥ 0，即 F·h ≤ W·(b/2)。
- F 從 0 準靜態增加時，先到達 min(μsW, W·b/(2h)) 的那個門檻先發生。
- 滑動或傾倒之後的動畫為示意：滑動用 a = (F − μkN)g/m；傾倒假設 O 點不打滑，用繞 O 的轉動方程式。
- 「顯示地面支撐力的分布」用線性分布示意，合力大小為 N、作用點為 d。
