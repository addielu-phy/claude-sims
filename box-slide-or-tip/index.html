推木箱：先滑動，還是先傾倒？

範例 11｜摩擦力、力矩平衡與正向力作用點——互動動畫 + 三小題完整計算

題目

如圖，一重量 2 kgw 的均勻木箱寬度 2 公尺、高度 4 公尺，置於水平面上，已知木箱與地面間的靜摩擦係數為 μs = 0.5、動摩擦係數為 μk = 0.4，若於高度為 h 之 P 點施一水平力 F 推此木箱，則
  1. 使木箱恰將開始滑動的同時，亦恰開始以 x 軸為轉軸發生轉動，h 為何？
  2. 欲使木箱維持等速向左移動，且不使物體傾倒的 h 的最大值是？
  3. 若 h = 1.5 m，F = 0.8 kgw，則地面給予木箱之正向力對 x 軸的力矩為何？若可將正向力視為在接觸面上的單一位置作用，則此時正向力的施力點位置距離 O 點多遠？
先想一想，再看答案(1) 2 m　(2) 2.5 m　(3) 0.8 kgw·m（逆時針，即 +x 方向）；0.4 m。完整計算在下方「解題」區。

F–h 判斷圖可點或拖曳設定 F、h

從左往右＝F 慢慢變大。先碰到直線 F = μsN就先滑動，先碰到曲線 F·h = W×1就先傾倒。兩線交點就是第 (1) 題。

1. 先把題目翻成物理語言

  • 木箱寬 b = 2 m、高 H = 4 m，重量 W = 2 kgw。木箱均勻，所以重心 G 在正中央：離 O 點水平 1 m、高 2 m。
  • 推力 F 水平向左（−y 方向），作用在右側面、高度 h 的 P 點。
  • 地面給木箱兩個力：正向力 N（向上）與摩擦力 f（沿地面向右，阻止木箱向左）。
  • x 軸通過 O 點、垂直紙面（指出紙面）。O 是木箱左下角的稜邊：木箱被向左推而翻倒時，就是繞這條邊轉。

2. 力矩的正負號

本頁規定：使木箱繞 x 軸逆時針轉（也就是向左翻倒的方向）的力矩為正，順時針為負。用右手定則，逆時針的力矩指向 +x（指出紙面）。

3. 四個力對 x 軸的力矩：力矩 = 力 × 力臂

力臂是「轉軸到力的作用線的垂直距離」，不是轉軸到作用點的距離。

力作用線力臂對 x 軸的力矩轉向
F高度 h 的水平線h+F·h逆時針
W通過 G 的鉛直線（y = 1 m）1 m−W × 1順時針
N距 O 點 d 的鉛直線d+N·d逆時針
f就在地面上，通過 x 軸00—

選 O 點的 x 軸當轉軸的好處：摩擦力 f 的力矩是 0，方程式最少一個未知數。

4. 平衡的三個方程式（靜止、或等速度平移都適用）

① 鉛直方向：N − W = 0　⇒　N = W = 2 kgw
② 水平方向：f − F = 0　⇒　f = F
③ 對 x 軸力矩：F·h − W×1 + N·d = 0　⇒　d = (W×1 − F·h) ÷ N
核心觀念：兩個「會自動調整、但有上限」的力
● 摩擦力 f 會自動等於 F，但最多只能到 μsN。f = μsN 就是恰將滑動。
● 正向力的作用點 d 會自動移動來維持力矩平衡：F·h 越大，d 越靠近 O。但 d 不能小於 0，因為正向力只能出現在木箱與地面接觸的地方。d = 0 就是恰將傾倒：木箱右下角恰要離地，地面只在 O 點撐住木箱。

所以有兩個上限：不滑動需要 F ≤ μsN；不傾倒需要 F·h ≤ W×1。右側的「F–h 判斷圖」就是把這兩個不等式畫出來。

第 (1) 題：恰將滑動，同時恰將以 x 軸轉動，h = ?

  1. 寫出「恰將滑動」的條件
    木箱還沒動，摩擦力是靜摩擦力；「恰將滑動」表示靜摩擦力已經達到最大值：
    f = fs,max = μsN
  2. 鉛直方向力平衡，求 N
    鉛直方向只有 N（向上）和 W（向下）：
    N − W = 0　⇒　N = W = 2 kgw
  3. 算最大靜摩擦力
    fs,max = μsN = 0.5 × 2 = 1 kgw
  4. 水平方向力平衡，求 F
    水平方向只有 F（向左）和 f（向右）：
    F = f = 1 kgw
  5. 寫出「恰將以 x 軸轉動」的條件
    恰將繞 O 點翻倒時，木箱右下角恰要離地，地面只剩 O 點撐住木箱，所以 N 的作用點就在 O：
    d = 0（N 與 f 都通過 x 軸，力矩都是 0）
  6. 對 x 軸列力矩平衡
    逆時針為正。F 的力臂是 h（逆時針）；W 的力臂是 1 m（順時針）：
    Στ = F·h − W×1 + N×0 + f×0 = 0
  7. 代入數字，解出 h
    1 × h − 2 × 1 = 0　⇒　h = 2 ÷ 1 = 2 m
答：h = 2 m此時 F = 1 kgw、f = 1 kgw（最大靜摩擦）、N = 2 kgw 集中在 O 點。

延伸：用文字式看出規律

把步驟 3、4、7 合起來：μsW · h = W · (b/2)，所以

h = b ÷ (2μs) = 2 ÷ (2 × 0.5) = 2 m（W 消掉了：答案跟木箱多重無關）

h 決定誰先發生：F 從 0 慢慢變大時，滑動要等 F 到 1 kgw；傾倒要等 F·h 到 2 kgw·m，也就是 F = 2/h。

施力高度 h開始滑動需要 F開始傾倒需要 F = 2/h先發生
1.5 m1 kgw1.33 kgw滑動
2 m1 kgw1 kgw同時（本題）
3 m1 kgw0.67 kgw傾倒

推得越高越容易推倒；推得越低越容易推動。這也是搬重物時要推下半部的原因。

第 (2) 題：等速向左移動且不傾倒，h 的最大值 = ?

  1. 「等速」代表什麼？
    等速度 ⇒ 加速度 a = 0 ⇒ 合力 = 0。木箱只平移、不轉動 ⇒ 角加速度 α = 0 ⇒ 合力矩 = 0。所以和靜止一樣，可以用力平衡和力矩平衡。
    ΣF = 0，Στ = 0
  2. 滑動中的摩擦力是動摩擦力
    f = fk = μkN
  3. 鉛直力平衡，再算動摩擦力
    N = W = 2 kgw　⇒　fk = 0.4 × 2 = 0.8 kgw
  4. 水平力平衡，F 被決定了
    F = fk = 0.8 kgw（F 大於 0.8 會加速，小於 0.8 會減速，等速時只能剛好 0.8）
  5. 對 x 軸列力矩平衡，求 d
    F·h − W×1 + N·d = 0　⇒　0.8h − 2 + 2d = 0　⇒　d = (2 − 0.8h) ÷ 2
  6. 寫出「不傾倒」的條件
    正向力的作用點必須落在接觸面上，所以 d ≥ 0：
    (2 − 0.8h) ÷ 2 ≥ 0　⇒　0.8h ≤ 2
  7. 解出 h 的範圍
    h ≤ 2 ÷ 0.8 = 2.5 m
    取最大值時 d = 0：木箱一邊等速滑動、一邊恰將繞 O 點翻倒。
  8. 檢查答案合理嗎？
    2.5 m 小於箱高 4 m，P 點確實在木箱側面上。✓
答：h 的最大值 = 2.5 m文字式：hmax = b ÷ (2μk) = 2 ÷ (2 × 0.4) = 2.5 m

為什麼比第 (1) 題的 2 m 高？

動摩擦係數 0.4 比靜摩擦係數 0.5 小，所以維持等速只要 0.8 kgw，比起動時的 1 kgw 小。重力提供的「回正力矩」都是 W×1 = 2 kgw·m；推力變小，力臂 h 就可以拉長到 2 ÷ 0.8 = 2.5 m。

小提醒：轉軸跟著木箱移動也沒關係嗎？
沒關係。木箱做等速度平移時加速度和角加速度都是 0，此時「對任何一條軸」的合力矩都是 0，所以選隨木箱一起走的 x 軸照樣成立。

第 (3) 題：h = 1.5 m、F = 0.8 kgw，正向力的力矩與作用點

  1. 先判斷木箱的狀態
    μsN = 0.5 × 2 = 1 kgw ＞ F = 0.8 kgw
    若木箱原本靜止：推不動，仍靜止，靜摩擦力 f = F = 0.8 kgw。
    若木箱原本已在滑動：動摩擦力 μkN = 0.8 kgw = F，剛好等速。
    兩種情況都是「平衡」：N = 2 kgw、f = 0.8 kgw，答案相同。
  2. 確認不會傾倒
    F·h = 0.8 × 1.5 = 1.2 kgw·m ＜ W×1 = 2 kgw·m　✓
  3. 逐一寫出各力對 x 軸的力矩（逆時針為正）
    τF = +F·h = +0.8 × 1.5 = +1.2 kgw·m（逆時針）
    τW = −W×1 = −2 × 1 = −2 kgw·m（順時針）
    τf = 0（f 的作用線在地面上，通過 x 軸）
    τN = ?
  4. 力矩平衡，求 τN
    τF + τW + τf + τN = 0
    1.2 + (−2) + 0 + τN = 0　⇒　τN = 2 − 1.2 = +0.8 kgw·m
    正號表示逆時針，也就是 +x 方向（指出紙面）。
  5. 換算成 SI 單位（參考）
    0.8 kgw·m = 0.8 × 9.8 N·m = 7.84 N·m
  6. 由 τN = N·d 求作用點
    τN = N × d　⇒　0.8 = 2 × d　⇒　d = 0.8 ÷ 2 = 0.4 m
答：正向力對 x 軸的力矩 = 0.8 kgw·m（逆時針，+x 方向）；作用點距 O 點 0.4 m沒有推力時 d = 1 m（G 的正下方）；加了推力後，作用點往 O 移動了 F·h ÷ W = 1.2 ÷ 2 = 0.6 m。

換一條軸驗算：對重心 G 取力矩

平衡時，對任何軸的合力矩都是 0。改以通過 G、平行 x 軸的軸驗算（逆時針為正）：

力作用線與 G 的關係力臂力矩（kgw·m）
F = 0.8在 G 下方 2 − 1.5 = 0.5 m，向左推0.5−0.8 × 0.5 = −0.4（順時針）
f = 0.8在 G 下方 2 m，向右2+0.8 × 2 = +1.6（逆時針）
N = 2在 G 左方 1 − 0.4 = 0.6 m，向上0.6−2 × 0.6 = −1.2（順時針）
W = 2通過 G00
合計−0.4 + 1.6 − 1.2 = 0　✓

換軸後摩擦力就有力矩了，所以選 O 點的 x 軸計算比較省事。兩種算法得到同樣的 d = 0.4 m。

「把正向力視為單一位置作用」是什麼意思？

地面其實是用整個底面撐住木箱，靠近 O 的那一側被壓得比較緊。把這些分布的支撐力合成為一個合力 N，合力的作用點就是 d。勾選動畫下方的「顯示地面支撐力的分布」，可以看到推力越大，支撐力越往 O 集中。這裡用線性分布示意，題目只需要合力的位置。

常見迷思

✗「正向力一定作用在重心正下方」
只有在其他力對那一點沒有力矩時才成立。有水平推力時，正向力作用點會往前（O 那側）移動。
✗「恰將傾倒時正向力變成 0」
正向力仍然等於 W = 2 kgw，只是全部集中在 O 點。變成 0 的是木箱右側那一端的支撐力。
✗「摩擦力一定有力矩」
對 x 軸（在地面上）沒有，因為摩擦力的作用線就在地面上、通過轉軸。但對重心 G 就有（見第 (3) 題驗算）。
✗「等速運動不能用力矩平衡」
等速平移時 a = 0、α = 0，力平衡和力矩平衡都成立。
✗「第 (2) 題的 F 可以隨便給」
要等速，F 必須剛好等於動摩擦力 0.8 kgw。

想一想（先預測，再用上方動畫驗證）

Q1. 若 h = 3 m，F 從 0 慢慢增加，木箱先滑還是先倒？在 F 等於多少時發生？ 傾倒需要 F·h = 2，F = 2 ÷ 3 ≈ 0.67 kgw；滑動需要 F = 1 kgw。0.67 < 1，所以先傾倒，發生在 F ≈ 0.67 kgw。
Q2. 第 (3) 題中，若把施力點降到 h = 0.5 m（F 仍為 0.8 kgw），正向力作用點離 O 多遠？ d = (2 − 0.8 × 0.5) ÷ 2 = 1.6 ÷ 2 = 0.8 m。推得越低，作用點越靠近中央。
Q3. 若地面比較滑，μs 變成 0.25，第 (1) 題的答案變成多少？ h = b ÷ (2μs) = 2 ÷ 0.5 = 4 m，剛好是箱頂。地面越滑越難推倒。可以打開「進階」把 μs 調成 0.25 看判斷圖的交點移動。
Q4. 為什麼第 (1) 題的答案和木箱重量無關？ 滑動的門檻 μsW 與傾倒的門檻 W·(b/2)÷h 都和 W 成正比，令兩者相等時 W 消掉，只剩 h = b ÷ (2μs)。
